# GG

The alt tracker for World of Warcraft: every character, from every account, side by side in one window.

- Item level, Mythic+ rating and keystone
- Great Vault, bosses killed this week, quests and currencies
- Gear, enchants and gems of any character
- Two accounts in one window
- Raid lockouts, bonus rolls and character cards you can share in chat

## Download

- [CurseForge](https://www.curseforge.com/wow/addons/ggs)
- [Wago](https://addons.wago.io/addons/gg)

## Commands

- `/gg` opens the window
- `/ggconfig` opens the settings
- `/ggsetup` runs the first-time setup again
